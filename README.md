# 🌸 Japanese Lifestyle Website

An interactive hub that brings timeless Japanese lifestyle philosophies into everyday practice.  
From **Kaizen** (continuous improvement) to **Ikigai** (purpose), and from **Wabi-sabi** (beauty in imperfection) to **Shinrin-yoku** (forest bathing), this website blends cultural wisdom with modern interactive tools to inspire balance, harmony, and meaningful living.

## ✨ Features
- Dynamic navigation with smooth scroll and responsive menus  
- Interactive concept explorer with tooltips and glossary  
- Daily practice generator with streak tracking  
- Habit tracker with calendar and progress bars  
- Ikigai mapper (drag-and-drop circles)  
- Kaizen planner with micro-step breakdowns  
- Shinrin-yoku soundscape and breathing exercises  
- Kintsugi metaphor tool for image repair  
- Moai community builder for social circles  
- Theme modes: Light, Dark, Zen  

## 🛠️ Tech Stack
- HTML5 for semantic structure  
- CSS3 for responsive design and animations  
- JavaScript (ES6+) for interactivity and state management  
- Accessibility with ARIA roles and keyboard navigation  
- Performance optimizations (lazy loading, responsive breakpoints)
